# Study Habits and Student Well-being

### Project title
Study Habits and Student Well-being

### Purpose
This is a fictional psychology class project to understand how study habits affect student well-being. The purpose is to learn how to organize research material online using GitHub.

### Files
1. project_plan.docx - Contains timeline and goals of the project.
2. survey_draft.docx - Draft questions for student survey (fictional data only).
3. data_dictionary.xlsx - Explanation of variables used in the project.

### Team rules
1. All files will be named as projectname_version_date, e.g., project_plan_v1_20Oct.
2. All team members must write a clear commit message before saving any change.

### Privacy reminder
No personal records, real names, or identifiable participant data will be uploaded. Only fictional or non-sensitive data will be used.
